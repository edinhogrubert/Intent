# Custom Project Instructions

## Custom Commands Trigger Rules
- `#Retomar projeto Intent#`: Retoma as atividades de codificação e desenvolvimento do projeto Intent OS.
- `#Pausar projeto Intent#`: Pausa as atividades de desenvolvimento do projeto Intent OS.
- `#Retomar projeto jira#`: Entra no modo de assistência para popular e estruturar o Jira/Confluence (Epics, Features, User Stories, Tasks, DoD, DoR, etc.).
- `#Pausar projeto jira#`: Pausa a assistência referente ao Jira.
